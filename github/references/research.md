# Launch research

Use this reference only for `launch`.

- Research only claims needed for the requested public launch.
- Prefer primary sources: the repository, official package documentation, deployed product, and official policy pages.
- Record the source for any public claim that is not directly evident in the repository.
- Treat unavailable, ambiguous, or stale evidence as a reason to omit the claim.
- Do not expand launch scope into unrelated design, product, or marketing work.

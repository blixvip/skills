# Ambiguous or complex repositories

Use this reference only when the normal fast path is insufficient.

1. Separate intended changes from unrelated work using the current diff and recent commits.
2. Identify the smallest set of files and checks that support the requested publish action.
3. Preserve generated or unrelated changes unless the user explicitly includes them.
4. Prefer no-push preparation when remote ownership, visibility, or release scope remains unclear.
5. State the single blocker and required decision rather than broadening the audit.

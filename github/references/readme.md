# README guidance

Use this reference only when changing `README.md`.

- Derive every claim from inspected code, configuration, or executed checks.
- Prefer a minimal structure: purpose, prerequisites, install, run, test, and deployment only when each is supported.
- Include exact commands only when they were found in manifests, scripts, CI, or verified locally.
- Do not add badges, benchmarks, browser support, licensing, screenshots, roadmaps, or feature claims without evidence.
- If a fact is unknown, omit it instead of guessing.

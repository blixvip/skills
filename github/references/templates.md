# Repository-file templates

Use this reference only when adding repository files.

- Add the smallest file that solves the identified need.
- Start from existing project conventions before adding a new config, template, or workflow.
- Keep generated files, dependency directories, local environment files, build outputs, and credentials out of version control.
- Do not add a license, contribution policy, issue template, security policy, or CI workflow unless the user requested it or inspected project evidence makes it necessary.
- Review every new file in the staged diff before committing.
